# 奇门遁甲全书 · 时家转盘奇门

一部可离线阅读的奇门遁甲 HTML 全书，含古籍原文、白话注解与完整的现代排盘教学。

## 内容

- **基础篇**：源流、阴阳五行、干支、八卦九宫、九星八门八神
- **起局篇**：定局、布地盘、排天盘、八门、八神、完整排盘流程
- **断局篇**：用神、旺衰、空亡马星、格局、分类占断、实战案例
- **原文注解篇**：烟波钓叟歌全文逐段注解
- **附录**：定局表、六旬表、马星表、术语表、常见误区

## 使用

直接打开 `qimen-dunjia.html` 即可，无需构建、无需联网（字体与图片均在本地）。

## 说明

本书为传统文化研究与学习资料。奇门遁甲属传统术数，其推论不可验证，不应作为医疗、法律、投资、人事等现实决策的依据。
